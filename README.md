# Madhuban pure veg

Create a premium, visually rich, modern website for “Madhuban Pure Veg” — a pure vegetarian family restaurant.

IMPORTANT:

This should NOT look like a generic restaurant template, basic WordPress website, or a simple food-menu website.

The design should feel like a premium Indian hospitality brand: warm, elegant, welcoming, photographic, and slightly editorial.

Take inspiration from the DESIGN QUALITY and STORYTELLING approach of premium travel/hospitality websites, but create a completely original restaurant identity and layout.

The website should make visitors immediately want to:

1. See the food

2. Explore the menu

3. Visit the restaurant

4. Order/contact the restaurant

==================================================

BRAND DIRECTION

==================================================

Brand:

Madhuban Pure Veg

Positioning:

A warm, family-friendly pure vegetarian restaurant serving fresh Indian and Indo-Chinese food in a comfortable atmosphere.

Brand personality:

- Warm

- Premium

- Authentic

- Family-friendly

- Fresh

- Indian

- Comfortable

- Modern but not overly luxurious

Avoid:

- Generic green restaurant templates

- Excessive food-card layouts

- Excessive gradients

- Overuse of illustrations

- Corporate/SaaS appearance

- Huge amounts of text

- Too many UI elements

- Cartoon-style Indian graphics

VISUAL STYLE

==================================================

Create a premium editorial restaurant aesthetic.

Use:

- Large high-quality food photography

- Large typography

- Generous whitespace

- Asymmetric layouts

- Rounded image containers

- Soft organic shapes

- Elegant section transitions

- Subtle Indian-inspired decorative details

- Editorial-style compositions

- Layered images

- Thin borders

- Soft shadows

- Subtle grain/texture

- Minimal line illustrations

The website should feel carefully art-directed rather than assembled from components.

Photography should be the hero of the design.

Use real restaurant/food photography wherever images are provided.

Do NOT generate fake-looking food illustrations.

==================================================

RESPONSIVE DESIGN

==================================================

Desktop:

Premium editorial layout.

Tablet:

Simplify asymmetric layouts while maintaining hierarchy.

Mobile:

Do NOT simply stack the desktop layout.

Create a carefully designed mobile experience.

Hero:

Large readable heading

Full-height image

Easy-to-tap CTA buttons

Food:

2-column or horizontal scroll where appropriate.

Gallery:

Masonry-style mobile layout.

Menu:

Easy-to-read restaurant menu.

Navigation:

Hamburger menu.

Ensure:

- No horizontal overflow

- Images remain properly cropped

- Typography scales correctly

- Buttons are touch-friendly

- Sections maintain visual rhythm

==================================================

IMPORTANT DESIGN RULES

==================================================

The final website should feel like:

A premium Indian vegetarian restaurant brand.

NOT:

A WordPress template.

A generic restaurant website.

A SaaS landing page.

A collection of cards.

Prioritize visual storytelling.

Use photography as a major design element.

Create strong visual hierarchy.

Keep the interface clean.

Use whitespace intentionally.

Use green as the brand identity but balance it with cream, beige and photography.

The result should look polished enough to present directly to a real restaurant client.

Make the homepage feel memorable within the first 5 seconds.

DO NOT copy any existing website.

Create an original visual identity for Madhuban Pure Veg.
